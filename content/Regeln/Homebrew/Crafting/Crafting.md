Das System basiert auf folgenden Design Überlegungen und Regeln:
1. Komponenten müssen zunächst gesammelt werden, hierzu ist eine Aktion (*Abbauen, Jagen, Fischen, Kräutersammeln) erforderlich:
	1. 6,6: Komponente frei wählen
	2. 6: Komponente von Liste zufällig bestimmt
	3. 4/5: Komponente zufällig bestimmt aber ungewollte Aufmerksamkeit oder Verdacht erzeugt  
	4. 1/3: Keine Komponente gefunden und ungewollte Aufmerksamkeit oder Verdacht erzeugt
2. Die Liste der Komponenten
	1. Variiert je nach Biom
	2. Spieler können bei manchen Komponenten beim ersten finden, ein Merkmal für die Komponente wählen.
3. Monsterkomponenten, können eher im Zuge des Abenteuers gefunden bzw. von erlegten Monstern gewonnen werden. Sofern gewollt, könnte ein Wurf zum auffinden einer Kreatur genutzt werden.
4. Die Verarbeitung von Komponenten kann entweder auf Reisen bzw. während dem Rasten oder über ein Langzeitprojekt zwischen den Abenteuern erfolgen, dies hängt von der Art ab.
5. Es gibt nur eine Handvoll Rezepte mit konkreten Boni als Beispiel je Kategorie, weitere Kreationen können die Spieler frei vorschlagen, anhand der eingesetzten Komponenten und deren Merkmale

# Komponenten 
Die Kategorien in denen Materialien und Komponenten gesammelt werden können sind:

| Kategorie           | Bezugsattribut | Liefert            | Nutzt Merkmal                                                     |
| ------------------- | -------------- | ------------------ | ----------------------------------------------------------------- |
| Jagen               | Agilität       | Wild & Leder       | Auswählen aus<br>- Sensorik<br>- Emotion<br>- Physisch/Pysiologie |
| Materialien Abbauen | Muskeln        | Erz & Holz         | Fest vorgegeben Materialeigenschaft als Merkmal                   |
| Kräutersammeln      | Verstand       | Pflanzen & Kräuter | Fest vorgegeben Name als Merkmal                                  |
| Fischen             | Präsenz        | Fische             | Analog Jagen                                                      |
