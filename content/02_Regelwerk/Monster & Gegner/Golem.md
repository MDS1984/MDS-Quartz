# Golem
**Konstrukt** _2W Zäher Rohling (Einzeln)_
Farbpalette: Gealtertes Kupfer, Altes Holz, Antiquiertes Porzellan

 _Magisch animiertes Konstrukt, geformt aus verschiedenen Materialien. Sie folgen den Befehlen ihrer Ersteller bedingungslos._

 ---

|                         |                                |
| ----------------------- | ------------------------------ |
| ✦ Unnachgiebig          | ⚔️ Zermalmender Schlag         |
| ✦ Immunität gegen Magie | ⚔️ Donnernder Tritt            |
|                         | ⚔️ Rücksichtloser Sturmangriff |

 ---
 💭**Will** Seinen Befehlen im genauen Wortlaut folgen.
 🚫 **Will nicht** Unklarheit darüber was zutun ist.

 👂 Schleifgelenke, hohle dumpfe Geräusche
