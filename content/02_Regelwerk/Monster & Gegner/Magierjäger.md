# Magierjäger
**Konstrukt** _8W Elite Marodeur (Einzeln)_
Farbpalette: Kaltes Stahl, Beschwörenes Rot, Mystisches Blau

 _Ein gewaltiges Konstrukt, dass vom Geruch von Zaubern angezogen wird. Es pirscht durch Ruinen oder verfluchte Städte immer auf der Suche nach arkanen Kräften._

 ---

|                    |                     |
| ------------------ | ------------------- |
| ✦ Riecht Magie     | ⚔️ Schlag           |
| ✦ Arkane Resistenz | ⚔️ Magie kontern    |
| ✦ Metallplatten    | ⚔️ Mächtiger Sprung |

 ---
 💭**Will** unerlaubte Magie und deren Nutzer auslöschen.
 🚫 **Will nicht** die Spur seines Ziels verlieren. 
Wird ein bestimmtes **Passwort** aufgesagt, wird der Magiejäger inaktiviert.

 ---
 👁️ Glühende Runenplatten
 👂 Tiefes magisches Summen, Metallene klirrende Schritte
 👃 Kaltes Eisen, verbrannte Stoffe
 
 ---

| W   | Wie er Zauberwirker aufhält.                                  |
| --- | ------------------------------------------------------------- |
| 1   | **Kegel der Stille** ausgehend von seinem Körper.             |
| 2   | **Zieht Energie aus Magie** und wird dadurch stärker.         |
| 3   | **Verstrickende Netze** die paralysieren.                     |
| 4   | **Ketten oder Handschellen** die Magie blockieren.            |
| 5   | **Blitzmotten** angezogen von zaubern                         |
| 6   | **Polarisierendes Feld** was die Wirkung von Zaubern umkehrt. |
