# Basilisk
**Magische Bestie** _Elite Lauerer_
Farbpalette: Schuppiges Grün, Moosbraun, Steingrau

 _Ein gequälter Geist eines gebundenen Dschinns, der niemals in seine Heimat zurückkehren durfte._

 ---

|                             |                         |
| --------------------------- | ----------------------- |
| ✦ Schwerfälliges Schleichen | ⚔️ Versteinernder Blick |
| ✦ Stachelige Haut           | ⚔️ Beißen & Reißen      |
| ✦ Starker Geruchssinn       | ⚔️ Wegschleichen        |

 ---
 💭**Will** Später an einer köstlichen Statue knabbern.
 🚫 **Will nicht** Licht, das seine Verstecke offenbart.
 
 ---
 👁️ Schimmernde Schuppen, schlängelnde Spuren im Staub
 👂 Stille, schabendes Zischen, Knirschen von zerkautem Stein
 👃 Kreidiger Geruch von gemahlenem Stein, ausgedörrte Luft
 
 ---

| W   | Verstecke                                                  |
| --- | ---------------------------------------------------------- |
| 1   | Unter einer bröckelnden, aber noch benutzten Brücke.       |
| 2   | Im verwesenden Kadaver eines gefallenen Drachen.           |
| 3   | Im fünften Stock eines verfallenen Wachturms.              |
| 4   | In einem Feld voller halb aufgefressener Bärenstatuen.     |
| 5   | In einem Labyrinth aus rostigen, hallenden Rohren.         |
| 6   | Zwischen den verschlungenen Wurzeln eines riesigen Baumes. |
