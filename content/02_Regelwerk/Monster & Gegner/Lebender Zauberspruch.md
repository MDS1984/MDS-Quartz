# Belebter Zauberspruch
**Konstrukt** _- Zäher Taktiker (Einzeln)_
Farbpalette: Kühles Arkana, Pearlcent Essence, Unheimliche Hitze

 _Ein Fragment eines Zaubers, welches belebt wurde. Sie wandern in Bibliotheken oder patrouillieren auf alten Schlachtfeldern._

 ---

|               |                          |
| ------------- | ------------------------ |
| ✦ Immateriell | ⚔️ Zaubereffekt auslösen |
| ✦ Reine Magie | ⚔️ Magie konsumieren     |
|               | ⚔️ Zerstreuen & Sammeln  |

 ---
 💭**Will** Seine Magie akkurat und effizient einsetzen.
 🚫 **Will nicht** Zurückgehalten, gebannt oder verändert werden.
**Besiegt** löst einen [[02_Regelwerk/Talente/Zauberei|wilden Ausbruch]] aus

 ---
 👁️ fliegende Siegel, magisches Licht, tanzende Motten
 👂 Geflüsterte Beschwörung
 👃 verbranntes Pergament, Hinweis auf die Magieschule
 
 ---

| W   | Komische Herkunft             |
| --- | ----------------------------- |
| 1   | **Arkane Supergau**           |
| 2   | **Schlachtfeld Überbleibsel** |
| 3   | **Wilder Ausbruch**           |
| 4   | **Planare Instabilität**      |
| 5   | **Magierfluch**               |
| 6   | **Alchemistisches Rezept**    |
 
Moves Zaubereffekte je Schule:
- **Bannzauber:** Zauberkontern, Verbündeten Schützen
- **Beschwörung:** Imps beschwören, Dimensionstür mit Spieler
- **Erkenntnis:** Ein Geheimnis offenbaren, Omen
- **Verzauberung:** Geas, Gedächntnisverlust
- **Hervorrufung:** Explodieren, Blitzschlag
- **Illusion:** Spieler kopieren, Blindheit
- **Nekromantie:** Lebenskraftentzug, Tode wiederbeleben
- **Verwandlung:** Polymorph, Stärke des Bären
